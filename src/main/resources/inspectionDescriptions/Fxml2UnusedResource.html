Reports an embedded resource declaration that nothing in its FXML/2 document refers to.

A resource is referred to with the @name prefix notation, with the {ClassPathResource name} markup extension, or from another resource's payload, for example by a stylesheet @import.

This is advisory rather than a correctness problem: the compiler materializes the resource whether or not the document loads it, and code outside the document can load it by name. It is, however, usually an oversight, and an unused resource still costs build output and class-path space.
