Validates embedded resource declarations against the FXML/2 grammar, so that every problem the compiler reports for a <?resource ?> declaration is also reported in the editor.

An embedded resource is a text file declared directly in an FXML/2 document and materialized as a classpath resource next to the generated class: 

  <?resource styles.css text/css:
      .root { -fx-font-size: 1.1em; }
  ?>
Reported problems:
  • A declaration that does not follow the <?resource name [media-type]:content?> grammar, including a missing content separator and an unterminated quote.
  • A missing resource name.
  • A name that is not a portable file name: an empty name, . or .., a name containing a path separator or another character that is not portable in a file name, a name ending in a space or a dot, and a reserved device name such as CON.
  • A media type that does not follow the type/subtype grammar.
  • A media type declaring the same parameter more than once.
  • A charset parameter naming a charset that is unknown or is not a legal charset name.
  • A payload character that the selected charset cannot encode.
