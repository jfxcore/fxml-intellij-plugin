Reports an fx:subclass directive whose code-behind class does not exist.

The FXML compiler resolves the fully-qualified name declared by fx:subclass and fails with 'com.sample.MyControl' cannot be resolved when no such class is found.

Two quick-fixes are available:

  • Remove fx:subclass, which compiles the markup down to a standalone class named after the FXML file.
  • Create code-behind class, which creates the missing Java or Kotlin class next to the FXML file, extending the compiler-generated markup base class and calling initializeComponent(). This fix is offered only when the declared name is a fully-qualified name built from valid Java identifiers whose simple name matches the FXML file name, because the compiler rejects any other code-behind name.
