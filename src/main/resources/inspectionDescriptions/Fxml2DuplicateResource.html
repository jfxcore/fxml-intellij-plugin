Reports two embedded resource declarations in the same FXML/2 document that declare the same resource.

Names are compared ignoring case, because the resource file the compiler writes is named case-insensitively: value.txt and Value.txt would end up as the same file. The message names the position of the earlier declaration, which is the one that stays in effect.

Resource declarations are scoped to the entire document and may appear before, inside, or after the root element, so a declaration inside an element collides with one in the prolog just as two in the prolog would.
