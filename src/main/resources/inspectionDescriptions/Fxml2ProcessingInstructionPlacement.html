Reports an <?import?> or <?prefix?> processing instruction written inside an element.

XML permits a processing instruction anywhere in element content, and FXML/2 makes use of that: a <?resource ?> declaration is scoped to the whole document and may appear before, inside, or after the root element.

Import and prefix declarations are not: they are read only from the document's direct children. An import written inside a tag therefore parses cleanly and is then silently ignored at compile time.
